## 三步开始

1. **下载安装**：手机浏览器下载 APK → 点开安装（需允许「安装未知来源应用」）。
2. **五分钟设置**：首次打开按引导设置 6 位家长密码 → 选年级 / 科目 / 难度 → 开启无障碍、防误删等权限，全部变绿。
3. **开始答题**：「专注应用」默认「开启后直接答题」——点「开始答题」孩子直接从第一题开始答，答对解锁；也可在页内切回名单模式勾选要管理的 App。

详细操作、机型适配、防误删说明，见使用说明书。

## 主要功能

- **英语打字练习（v0.5.0，手机 / 平板）**：仿卡片闯关的单词打字练习——每关 8 个单词，先看（默认 3 秒，可调 1.5/3/5/8 秒）再藏起来默打，屏幕自带键盘逐字母校验（敲对前进、敲错红一下），支持听读与「看一眼」；打完结算星星，错词可立即回炉重练；每关当天首次 2 星及以上奖励 5 分钟解锁时长。练习本按年级推荐：小学～高中用 PEP 高频口语词，大学用四六级核心词
- **大学年级与四六级题库（v0.5.0）**：年级可选大一~大四，学段科目为语文 / 数学 / 英语 / 安全；每个年级独立 300 题四六级英语库，选大一不会抽到大四题
- **答题解锁**：答对设定题数才能解锁一段娱乐时长，答错加题数量可设置（0–5 题），错题进错题本
- **安全公益课堂（v0.4.0，免费）**：安全题库按学段分 5 库（小学/初中/高中/成人/老年）共 **2756 题**（v0.4.4 起删除 284 道敏感内容题），覆盖反诈、消防、交通、防溺水、用电居家、防拐骗、校园互助、食品安全、网络安全、急救自救、自然灾害、身体保护、健康生活 13 类，可混入孩子答题（约每 5 题 1 道）、难度「安全」卡专练、全家安全自测不占孩子额度；题目依据公安部、应急管理部、交通运输部等公开资料编写
- **时间花得明白（v0.3.59）**：解锁时长按实际使用结算，家长中途接管时没玩完的分钟数自动退还；家长端「孩子端演示」不占孩子的真实额度
- **游戏不打断**：时间到了孩子正在游戏里，会等这一局结束（结算 / 退出 / 切后台）再弹答题，减少亲子冲突；手机最多等 30 分钟、电视 15 分钟兜底（专业版功能）
- **稳定守护**：设备管理 + 无障碍守护 + 前台服务 + 自启动恢复，重启后依然有效（华为 nova7 实测）
- **忘记密码自助找回**：在家长设置的「修改密码」处设置密保问题（改密码时会温和提示，可跳过），答对即可自己重设家长密码，不用联系客服
- **手机 / 平板 / 电视全覆盖**：平板自动大屏布局；电视版遥控器全流程操作，适配不同品牌型号
- **低年级友好（v0.3.56）**：一、二年级题目带拼音注音；答题页可「朗读题目 / 朗读答案」，不识字也能读题
- **题库充足（v0.3.66）**：全部 66 个题库每库 150 题以上；专业版默认开启「题库扩充」共 10,000 题，长期答题不重样；干扰项已全面校准，答案不会因长度一眼被看出
- **分机型指导**：华为 / 荣耀 / vivo / iQOO 等品牌权限开关逐项引导
- **数据只存本机**：不注册、不联网采集，卸载即删除
