## 三步开始

1. **下载安装**：手机浏览器下载 APK → 点开安装（需允许「安装未知来源应用」）。
2. **五分钟设置**：首次打开按引导设置 6 位家长密码 → 选年级 / 科目 / 难度 → 开启无障碍、防卸载等权限，全部变绿。
3. **开始答题**：勾选要限制的娱乐 App → 点「开始答题」回到桌面。孩子打开受限应用就会看到「先完成答题解锁」。

详细操作、机型适配、防卸载说明，见使用说明书。

## 主要功能

- **答题解锁**：答对设定题数才能解锁一段娱乐时长，答错加题数量可设置（0–5 题），错题进错题本
- **时间花得明白（v0.3.59）**：解锁时长按实际使用结算，家长中途接管时没玩完的分钟数自动退还；家长端「孩子端演示」不占孩子的真实额度
- **游戏不打断**：时间到了孩子正在游戏里，会等这一局结束（结算 / 退出 / 切后台）再弹答题，避免硬打断引发亲子冲突；手机最多等 30 分钟、电视 15 分钟兜底（标准版功能）
- **防卸载四道防线**：设备管理 + 无障碍守护 + 前台服务 + 自启动恢复（华为 nova7 实测：重启后依然拦截）
- **忘记密码自助找回**：设置密保问题，答对即可自己重设家长密码，不用联系客服
- **手机 / 平板 / 电视全覆盖**：平板自动大屏布局；电视版遥控器全流程操作，适配不同品牌型号
- **低年级友好（v0.3.56）**：一、二年级题目带拼音注音；答题页可「朗读题目 / 朗读答案」，不识字也能读题
- **题库充足**：小学语文、英语每个难度 50 题以上，不容易背答案
- **分机型指导**：华为 / 荣耀 / vivo / iQOO 等品牌权限开关逐项引导
- **数据只存本机**：不注册、不联网采集，卸载即删除
